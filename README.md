# Laundry Wallah / Laundry Mart

## About the Project

Laundry Wallah / Laundry Mart is a simple HTML webpage created for a laundry service.
The webpage provides information about the laundry services, pricing, and booking options.
It is designed to provide users with a simple and easy-to-understand experience.
The website includes different sections such as About Us, Services, Price List, and Book Now.
Users can also find contact information in the footer section.

## Features

- Welcome header section
- About Us section
- Laundry service image
- List of laundry services
- Price List in a table
- Book Now form
- Required fields for Name, Email, and Phone
- Contact information in the footer

## Services

- Washing and Drying
- Ironing and Folding
- Dry Cleaning
- Stain Removal
- Express Services
- Special Garment Care

## Technologies Used

- HTML5

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the `index.html` file.
4. Open it in a web browser to view the webpage.
